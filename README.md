# 🛡️ Modbus & Industrial Traffic Anomaly Detection (IDS/IPS)

Спеціалізований інструмент на Python для моніторингу, аналізу та автоматичного виявлення загрози у промисловому мережевому трафіку (SCADA/ICS) на базі протоколу **Modbus TCP** та SSH.

Проєкт реалізує функції **IDS (Система виявлення вторгнень)** та **IPS (Система запобігання вторгненням)** з підтримкою як аналізу готових `.pcap` дампів, так і роботи у режимі реального часу (Live Capture).

---

## 🚀 Основний функціонал

* **Глибокий аналіз пакетів (PCAP Analysis):**
  * Інтерактивний перегляд та структурований/деталізований розбір пакетів у PCAP-файлах за допомогою бібліотеки `Scapy`.
* **Автоматичне виявлення аномалій (IDS):**
  * Ідентифікація несанкціонованих та підозрілих IP-адрес (наприклад, атак із Kali Linux / IP Spoofing).
  * Детекція критичних/небезпечних функціональних кодів Modbus (наприклад, опитування станцій, запис у регістри чи команди керування `Write Coils/Registers`: `1, 5, 6, 15, 16`).
* **Моніторинг у режимі реального часу (Live Capture):**
  * Захоплення трафіку з мережевого інтерфейсу (`enp0s3`) за фільтрами `TCP 502` (Modbus) та `TCP 22` (SSH).
  * Захист від DoS/DDoS атак: відстеження Rate Limit за допомогою ковзного часового вікна (`Time Window`).
* **Активний захист (IPS Action):**
  * Автоматичне блокування IP-адреси нападника у брандмауері Linux (`iptables`) при виявленні DoS-атаки.
* **Логування та збереження дампу:**
  * Запис алертів у файл `alerts.log`.
  * Автоматичне збереження підозрілих пакетів у файл `live_attacks_captured.pcap`.

---

## 🛠️ Використані технології

* **Мова розробки:** Python 3
* **Мережевий аналіз:** `Scapy` (з розширенням `scapy.contrib.modbus`)
* **ОС та інструменти безпеки:** Linux (Ubuntu/Debian), `iptables`
* **Протоколи:** Modbus TCP, TCP/IP, SSH

---

## 📁 Структура проєкту

* `main.py` — основний скрипт із меню, логікою аналізу та захоплення трафіку.
* `*.pcap` — тестові та зафіксовані дампи мережевого трафіку (включаючи SSH, Modbus та зразки атак).
* `alerts.log` — журнал сповіщень про безпекові події.
