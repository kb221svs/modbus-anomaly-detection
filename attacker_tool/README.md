# ⚡ Modbus TCP Attack Generator & OpenPLC Management Tool

Спеціалізований скрипт на Python для тестування систем захисту (IDS/IPS) та оцінки вразливості промислових систем керування (**ICS/SCADA**).

Інструмент поєднує в собі функціонал **генератора симульованих атак (Modbus TCP)** для перевірки спрацьовування правильних сповіщень та **віддаленого керування ПЛК** через захищене SSH-з'єднання з використанням утиліти `modpoll`.

---

## 🛠️ Основні можливості

* **Симуляція Modbus TCP атак (Attack Module):**
  * Пряме підключення до контролера (ПЛК) за протоколом Modbus TCP (порт 502).
  * Автоматизоване надсилання послідовностей критичних команд:
    * Запис у поодинокі та множинні котушки (`write_coil`, `write_coils`).
    * Запис у поодинокі та множинні регістри (`write_register`, `write_registers`).
  * Налаштування кількості циклів атак для перевірки спрацьовування обмежень частоти запитів (**Rate Limiting / DoS Detection**).

* **Дистанційне керування OpenPLC через SSH (PLC Control):**
  * Захищена авторизація на ПЛК через SSH за допомогою ключа `Ed25519` (бібліотека `Netmiko`).
  * Виконання технологічних команд у контролері за допомогою `modpoll`:
    * `1` — Запуск системи (Start sequence).
    * `2` — Перемикання вимикача (Breaker Switch).
    * `3` — Зупинка системи (Stop sequence).

---

## 🧰 Використані бібліотеки та стек

* **Python 3**
* **`pymodbus`** — для взаємодії з ПЛК на низькому рівні за протоколом Modbus TCP.
* **`netmiko`** — для автоматизації та виконання команд через SSH.
* **`modpoll`** — утиліта CLI на стороні ПЛК для маніпуляції регістрами та дискретними входами/виходами.
